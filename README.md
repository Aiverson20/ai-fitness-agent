# AI 健身团队

一支跑在 **Trae Work + 飞书** 上的私人定制 AI 健身管家：训练师定训练计划，营养师管三餐，监督员打卡打分，鼓励师每晚收尾，大总管统一对接。电脑负责一次性搭建，手机负责每天的日常使用。

## 它能做什么

| 角色 | 负责 |
|---|---|
| 大总管 | 唯一对接人，你的所有消息先到它这里 |
| 训练师 | 采集体测数据，按双周节奏滚动定制训练计划 |
| 营养师 | 三餐照片自动识别，记录热量与营养素 |
| 监督员 | 核对当天训练与饮食，给出当日分数 |
| 鼓励师 | 每晚生成「晚间汇报」卡片收尾 |

## 安装（三步）

需要准备：一台电脑、一部手机、一个飞书账号。

### 01 电脑端：安装 Trae Work

官网下载安装，登录个人账号。建议顺手签到——赠送的积分就是 AI 干活的额度。

### 02 手机端：安装飞书并连接

手机安装飞书，电脑打开 Trae Work 的「办公助理」，扫码连接。

### 03 一句话，让 AI 完成安装

在 Trae Work 新建任务，把这句话发给 AI：

> 帮我把 GitHub 上的 AI 健身团队装到这台电脑：https://github.com/Aiverson20/ai-fitness-agent

之后 AI 会自动完成部署并打通飞书通道。**手机飞书收到团队的第一条消息，就是安装成功的标志**——跟着它的提示完成建档，你的专属健身团队就上线了。

仓库根目录的 `fitness-team-agent.zip` 是分发包，安装指令会自动处理，无需手动下载。

## 装好之后，每天就三件事

1. 练完，在飞书里说一声「训练完成」
2. 三餐拍照发过去，它自动识别并记录
3. 晚上等一张「晚间汇报」卡：分数、三餐小结、今日寄语

搭建只做一次，之后全部在手机上。

## 设计理念

AI 负责了解你、采集你、安排你、记录你；动作的事，交给专业的人。所以这支团队不教动作、不纠正姿势——它把自己擅长的了解、安排与记录做到位，把动作指导留给专业的人。
